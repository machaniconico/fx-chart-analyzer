# セッション限定EA候補の事前登録台帳

セッションフィルタ変異(`--session-variants`)で好成績を出した候補を**採用前に**ここへ登録し、後日の再現確認を経てから採用判断する。台帳の目的は「良い結果を見てから登録する」後知恵を禁じ、**登録時点のパラメータを固定して将来データでの再現だけを合否にする**こと。

## 採用プロトコル

1. **事前登録**: チューニングランで目を引いたセッション候補を、その時点のパラメータ(SL/TP/TR/セッション窓)ごと本台帳に記録する。登録後のパラメータ変更は不可(変更したら新規登録として扱い、確認期間はリセット)。
2. **再現確認**: 登録から**4週間以上**経過後の深履歴チューニングランで、同一候補(同一セッション・同一パラメータが選定されるか、または同一パラメータ固定で評価して)が誠実ゲートを再度通過すること。
3. **安定性検査**: `--walk-forward`(四半期安定性)で正のセグメントが3/4以上であること。
4. 上記を全て満たした候補のみ、通常の in-sample ランキングでの採用検討対象になる。

**背景(なぜこの手順が要るか)**: セッション変異は候補あたりの組合せ空間を4倍にする。2026-08-17のランでは合格76候補中**66がセッション付きを選定**した — 選択肢が4倍あれば in-sample の見かけ最良がセッション付きになるのはほぼ必然で、これは勝者の呪い(選択バイアス)の兆候そのもの。単一ランの成績では「実エッジ」と「選択による見かけ」を区別できないため、時間を跨いだ再現のみを証拠として扱う。

- **東京セッション偏重**: 上位のセッション付き候補は東京(00:00-08:00 UTC)が多数を占める。円クロスの東京仲値・実需フローという実エッジ仮説は立つが、GBPUSD(円と無関係)まで東京が最良になっており、人工物の可能性を否定できない。再現確認で判別する。
